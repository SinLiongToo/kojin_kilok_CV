📌 Bridging PRD & Gantt Charts! I Built a Boundary-Safe Smart Project Planner

I built this tool while preparing for my Black Belt examination... and let me tell you, it was tough, literally! Managing rigorous statistical concepts made me realize we needed a leaner, more bulletproof way to sync documentation with execution timelines.

In large-scale engineering and hardware validation workflows, project management usually hits two major friction points:

1. The Alignment Gap: Writing a PRD and drawing a Gantt chart require different software. The data is never perfectly synced.
2. The Schedule Slippage: Shuffling tasks around often causes accidental overruns past the target deadline due to a lack of immediate boundary constraints.

To solve this, I built the 【Adaptive PRD & Gantt Planner App v9.1】!

✨ Core Features:

📊 Time-Boundary Constraints: Set your active weeks and launch targets. The system enforces these boundaries, instantly triggering a red "CRITICAL Overrun" warning if a downstream schedule slips past the deadline.
👥 Dynamic Stakeholder Matrix:Easily assign an Owner/Name alongside core, explicit responsibilities for every key project role.
📝 Notion-Style Sync: Left-side inputs instantly compile into high-contrast tables and crisp Markdown documentation on the right via a Live Preview or Source Code tab.
💾 Zero-Loss Auto-Save: Powered by localStorage, every keystroke is saved instantly in your browser sandbox.
🖨️ Single-Click Export: Instantly download a high-res PNG of your Gantt chart, or print a clean, distraction-free PDF report.

This project applies a continuous improvement mindset to software layout. It proves that with clean Web technologies, we can dramatically scale team alignment and eliminate manual friction.
